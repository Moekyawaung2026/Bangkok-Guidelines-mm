# Bilingual Translation Guide (Myanmar & Thai)

## Standards
1. **Unicode Compliance**:
   - Only Standard Myanmar Unicode is permitted.
   - Never use Zawgyi or ad-hoc legacy encodings.

2. **No Blind Transliteration**:
   - Proper nouns must retain Thai script alongside Burmese pronunciation and English Romanization.
   - Example:
     - Burmese: အောင်ဆန်းရတနာ အောင်ပွဲရုပ်တု ဘတ်စ်ကားမှတ်တိုင်
     - Thai: ป้ายรถเมล์อนุสาวรีย์ชัยสมรภูมิ
     - Romanized: Victory Monument Bus Stop

3. **Colloquial Clarity**:
   - Use straightforward language accessible to factory workers, construction workers, and domestic helpers.
   - Provide phonetic guidance for Thai tones so drivers understand clearly when spoken.
