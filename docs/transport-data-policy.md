# Transport Data & Freshness Policy

1. **No Simulated or Hallucinated Arrivals**:
   - The platform never fabricates real-time GPS arrivals. If live data is unavailable or the user is offline, the system clearly marks:
     `“လက်ရှိအခြေအနေ မရရှိနိုင်ပါ (Live status unavailable - showing estimated schedule)”`

2. **Verification Labels**:
   - Every station, bus route, and fare must carry:
     - Verified timestamp: `အချက်အလက် နောက်ဆုံးစစ်ဆေးချိန်`
     - Confidence score: `Confidence Score %`
     - Source organization

3. **Community Reports**:
   - Community-submitted corrections are stored separately as `အသုံးပြုသူတင်ပြချက်` until verified by moderators.
