# Contributing to Bangkok Go MM

Thank you for your interest in improving Bangkok Go MM for Myanmar workers and travelers in Thailand.

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/NewTransportFeature`).
3. Commit your changes (`git commit -m 'Add new verified BMTA bus line'`).
4. Ensure all unit and Robolectric tests pass (`gradle testDebugUnitTest`).
5. Push to the branch (`git push origin feature/NewTransportFeature`).
6. Open a Pull Request.

## Translation Guidelines
- Strictly use **Myanmar Unicode** (Pyidaungsu / Noto Sans Myanmar). Never use Zawgyi font.
- Keep translations simple, clear, and colloquial for everyday workers.
- Avoid transliterating Thai place names blindly; always provide native Thai script, Burmese script, and Romanized English.
